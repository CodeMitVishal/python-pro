Lesson · Unpacking

Pull values out and into names, in one step

x, y = (3, 7) # basic a, b = b, a # swap, no temp first, *middle, last = nums # * = "the rest" name, _, city = record # _ = ignore area(*[4, 5]) # list -> args area(**{"width": 2, "height": 9}) merged = [*odds, *evens] settings = defaults | user # later keys win

Lesson · Lists & tuples under the hood

A list is a row of references, with spare room

b = a # same list, 2 names c = a.copy() # new outer list (shallow) d = copy.deepcopy(grid) # copies inner lists too
LIST

Changeable. Grows and shrinks. Use for collections of similar items.

TUPLE

Read-only and lighter (56 vs 72 bytes for 2 items). Hashable, so it can be a dict key. Use for fixed records: (x, y), RGB, DB rows.

⚠️ A shallow copy shares the inner lists. Nested data? Use copy.deepcopy.

Lesson · Dicts, sets & hashing

Dicts don't search. They jump straight to the answer.

Keys must be hashable = immutable: str int tuple frozenset. Not list, dict or set.

Set opMeans
a | bin either (union)
a & bin both (intersection)
a - bonly in a (difference)
a ^ bin exactly one

Dicts keep insertion order. Dedupe and keep order: list(dict.fromkeys(xs))

NAMEDTUPLE

A tuple with field names

Point = namedtuple("Point", ["x", "y"]) Point(3, 7).x # 3

Lesson · dataclasses

Classes for data, without the boilerplate

@dataclass class Product: name: str price: float qty: int = 0 # default tags: list = field(default_factory=list) def total(self) -> float: return self.price * self.qty Product("Laptop", 899.0, 2) # Product(name='Laptop', price=899.0, qty=2, tags=[])
YOU GET FOR FREE

__init__ · __repr__ · __eq__, built from the fields.

OPTIONS

frozen=True → read-only and hashable
order=True → sortable by the fields
asdict(obj) → plain dict (great for JSON)

⚠️ Never tags: list = []. Every object would share one list. Use field(default_factory=list).
