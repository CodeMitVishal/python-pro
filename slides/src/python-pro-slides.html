Lesson · Parameters

*args, **kwargs, keyword-only and the trap

def f(a, b=2, *args, c, d=4, **kwargs): # | | | | | └ extra keywords -> dict # | | | └──┴ keyword-only (after *) # | | └ extra positionals -> tuple # | └ default # └ positional def connect(host, *, port=443): ... connect("api.io", port=8080) # must name it def add(item, basket=None): # NOT basket=[] if basket is None: basket = [] basket.append(item) return basket

*args collects extra positional arguments into a tuple, **kwargs extra keywords into a dict.

Everything after a bare * must be passed by name: call sites explain themselves.

⚠️ Default values are created once. A [] default is shared by every call. Use None.

Lesson · Scope & closures

A function that remembers

def make_counter(): count = 0 def next_number(): nonlocal count # update the OUTER count count += 1 return count return next_number # the function, not a call c1, c2 = make_counter(), make_counter() c1(), c1(), c1(), c2() # 1 2 3 1

LEGB: Python looks for a name in Local → Enclosing → Global → Built-in.

A closure keeps the variables of its outer function alive, even after it returned.

Reading an outer variable just works. Assigning needs nonlocal (or global).

Lesson · The iteration protocol

What a for loop really does

for x in things: # is really: print(x) it = iter(things) # iterable -> iterator while True: try: x = next(it) # next item... except StopIteration: # ...until there's none break print(x)

Iterable: something you can loop over. It hands out an iterator (__iter__).

Iterator: remembers where you are and gives the next item (__next__).

An iterator is used up after one pass: list(it) twice gives [] the 2nd time.

Lesson · Generators

yield: hand out a value, pause, resume

def countdown(start): while start > 0: yield start # hand out + PAUSE here start -= 1 # resume here on next() list(countdown(3)) # [3, 2, 1] squares = (n*n for n in range(10**6)) # generator expression sum(squares) # one value at a time

Calling a generator function runs nothing; it returns a generator object.

Each next() runs to the next yield and keeps all local variables.

yield from xs hands over to another iterable.

Memory: a list of 1M squares = 8.4 MB, the generator = 200 bytes.

Chain generators like an assembly line

lines = read_lines(path) # yields one line at a time records = parse(lines) # yields (date, level, msg) errors = only("ERROR", records) # filters lazily msgs = messages(errors) # formats lazily for m in islice(msgs, 2): # take 2, then stop print(m) # only 4 lines were ever read!

Lesson · Exceptions

Your own exception family

class ShopError(Exception): ... # the family class OutOfStock(ShopError): def __init__(self, item, left): super().__init__(f"only {left} x {item} left") self.item, self.left = item, left # extra data try: buy("laptop", 5) except OutOfStock as e: # most specific FIRST print(e.left) except ShopError as e: # then the family ... raise ShopError("config broken") from err # keep the cause

Catch as specific as possible; a parent catches all its children.

raise ... from e keeps the original error in the traceback.

EAFP: try it, handle the exception. The Pythonic default.

⚠️ Never except: pass. It also catches Ctrl+C and hides bugs forever.

Lesson · Threads

Shared data needs a lock

counter = 0 lock = threading.Lock() def safe_add(n): global counter for _ in range(n): with lock: # one thread at a time counter += 1 # 4 threads x 1000: # without the lock: 1204 <- updates lost! # with the lock: 4000

A race condition: two threads read, both add 1, both write. One update is lost.

with lock: makes the read-modify-write happen as one step.

Simplest of all: don't share. Return results from the pool instead.

Lesson · asyncio

Thousands of waiting tasks on one thread

async def fetch(name, s): await asyncio.sleep(s) # pause, let others run return name async def main(): results = await asyncio.gather(fetch("x", 1), fetch("y", 1)) # ~1 s await asyncio.wait_for(fetch("slow", 5), timeout=0.5) # TimeoutError limit = asyncio.Semaphore(10) # max 10 at once asyncio.run(main())

Switches happen only at await, so race conditions are rarer.

gather = run concurrently · wait_for = timeout · Semaphore = limit.

⚠️ One blocking call (time.sleep, requests.get) freezes the whole loop.
