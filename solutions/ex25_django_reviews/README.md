# Solution · Exercise 25: book reviews

Copy these files into `25_django/bookstore_project/catalog/` (replacing the
originals), plus `0002_review.py` into `catalog/migrations/`, and
`exercises/ex25_test_reviews.py` as `catalog/tests_reviews.py`. Then:

```bash
python manage.py migrate
```

```bash
python manage.py test
```

Changes compared with the starting project:

| File | Change |
|---|---|
| `models.py` | new `Review` model with 1–5 validators and `related_name="reviews"` |
| `admin.py` | `Review` registered in the admin |
| `serializers.py` | `ReviewSerializer` with `validate_rating`; `avg_rating` on `BookSerializer` |
| `api.py` | `BookViewSet` annotates `Avg("reviews__rating")`; new `ReviewViewSet` with `?book=` filter |
| `urls.py` | `router.register("reviews", ...)` |
| `0002_review.py` | the migration generated by `makemigrations` |
