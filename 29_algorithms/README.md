# Module 29 · Algorithms & data structures

[← Back to the course](../README.md) · [Slides](../slides/python-pro-slides.pdf)

These are the classic algorithms and patterns behind coding interviews, built from scratch in plain Python and timed so you can see Big-O happen.

## Lessons

| Lesson | File | Key idea |
|---|---|---|
| Sorting & searching | [`01_sorting_and_searching.py`](01_sorting_and_searching.py) | bubble, insertion, merge, quick sort; stable sorts; binary search |
| Stacks, queues, linked lists | [`02_stacks_queues_linked_lists.py`](02_stacks_queues_linked_lists.py) | balanced brackets, `deque`, reverse a linked list |
| Trees | [`03_trees.py`](03_trees.py) | binary search tree, traversals, height, level order |
| Graphs | [`04_graphs.py`](04_graphs.py) | BFS, DFS, Dijkstra, topological sort |
| Dynamic programming | [`05_dynamic_programming.py`](05_dynamic_programming.py) | coin change, edit distance, LCS, knapsack |
| Problem-solving patterns | [`06_problem_solving_patterns.py`](06_problem_solving_patterns.py) | hash map, two pointers, sliding window, prefix sums |
