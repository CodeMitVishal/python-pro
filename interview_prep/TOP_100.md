## Python core ([08](../08_pythonic_code/INTERVIEW.md) · [09](../09_data_structures/INTERVIEW.md) · [10](../10_advanced_functions/INTERVIEW.md) · [11](../11_iterators_generators/INTERVIEW.md))

1. **List vs tuple?** A list is mutable (many similar items). A tuple is immutable (a fixed record) and hashable, so it can be a dict key.
2. **Mutable vs immutable types?** int, float, str, tuple, frozenset and bytes can't change. list, dict and set can.
3. **`is` vs `==`?** `is` checks identity (the same object). `==` checks value. Use `is` only for `None`, `True` and `False`.
4. **How does a dict work?** It's a hash table: `hash(key)` picks a slot, so operations are O(1) on average. Keys must be hashable. Insertion order is kept.
5. **Shallow vs deep copy?** A shallow copy shares nested objects. `copy.deepcopy` copies everything.
6. **What are `*args` and `**kwargs`?** Extra positional arguments go into a tuple; extra keyword arguments go into a dict.
7. **The mutable default argument trap?** Defaults are created once, so `def f(x=[])` shares one list. Use `None`.
8. **LEGB?** The name lookup order: Local, Enclosing, Global, Built-in.
9. **What is a closure?** An inner function that remembers variables of its enclosing scope. Changing them needs `nonlocal`.
10. **What is a decorator?** A function that takes a function and returns a wrapped one. `@d` means `f = d(f)`. Use `functools.wraps`.
11. **Decorator with arguments?** Three levels: settings → decorator → wrapper.
12. **Order of stacked decorators?** They apply bottom-up and run top-down.
13. **What is a lambda?** An anonymous one-expression function, typically used for `key=`.
14. **`map`/`filter` vs comprehensions?** Comprehensions are usually clearer, and just as fast.
15. **What is a generator?** A function with `yield` that produces values lazily, one at a time, using constant memory.
16. **Iterable vs iterator?** An iterable has `__iter__` and can produce iterators. An iterator has `__next__`, keeps a position and is single-use.
17. **List comprehension vs generator expression?** `[]` builds everything now; `()` is lazy.
18. **What does `yield from` do?** It delegates to a sub-iterator.
19. **How do you read a 10 GB file?** Iterate over the file object line by line, or read it in chunks.
20. **What is `with` / a context manager?** Guaranteed setup and teardown (`__enter__`/`__exit__`), even when errors occur.
21. **What are `@staticmethod` and `@classmethod`?** A staticmethod gets nothing. A classmethod gets `cls`, which makes it good for alternative constructors.
22. **`__str__` vs `__repr__`?** `__str__` is for users; `__repr__` is for developers and should be unambiguous.
23. **What are dunder methods?** Special methods behind built-in syntax: `__len__`, `__eq__`, `__add__`, `__iter__`...
24. **What is `if __name__ == "__main__"`?** It runs that code only when the file is executed directly, not when it's imported.
25. **Module vs package?** A module is a `.py` file. A package is a folder of modules.
26. **What is a virtual environment?** A per-project interpreter with its own libraries, isolated from other projects.
27. **What are type hints?** Annotations that checkers like mypy use. They aren't enforced at runtime, except by libraries like Pydantic and FastAPI.
28. **What is EAFP?** "Try it and catch the error" rather than checking everything first.
29. **What is the walrus operator?** `:=` assigns and returns in one expression.
30. **What does `match`/`case` do?** Structural pattern matching on the shape of data.

## OOP ([12](../12_advanced_oop/INTERVIEW.md))

31. **What are the four pillars?** Encapsulation, abstraction, inheritance and polymorphism.
32. **What is the MRO?** The C3-linearised order in which classes are searched. `super()` calls the next class in the MRO.
33. **Composition vs inheritance?** Has-a vs is-a. Prefer composition with dependency injection.
34. **ABC vs Protocol?** An ABC is nominal (you must inherit). A Protocol is structural (you just match the methods).
35. **What is `@property`?** Attribute-style access with getter and setter logic.
36. **What is `__slots__`?** A fixed set of attributes with no `__dict__`, which saves memory.
37. **`__new__` vs `__init__`?** `__new__` creates the object; `__init__` initialises it.
38. **What is SOLID?** Single responsibility, Open/closed, Liskov substitution, Interface segregation, Dependency inversion.
39. **Which design patterns have you used?** Factory, strategy, repository, observer, decorator, and singleton (as a module).
40. **What is a metaclass?** The class of a class. It customises class creation (`__init_subclass__` is usually enough).

## Errors, internals, performance, concurrency ([13](../13_errors_context_logging/INTERVIEW.md) · [17](../17_concurrency/INTERVIEW.md) · [19](../19_performance_internals/INTERVIEW.md))

41. **Why is a bare `except:` bad?** It hides bugs and catches Ctrl+C. Catch specific exceptions.
42. **What does `raise ... from e` do?** It chains exceptions and keeps the original cause.
43. **Why logging instead of print?** Levels, timestamps, handlers and tracebacks, all configurable.
44. **How does Python manage memory?** Reference counting plus a cyclic garbage collector, on a private heap.
45. **Pass by value or reference?** Pass by object reference: mutating the object is visible to the caller, rebinding the name isn't.
46. **What is the GIL?** It lets one thread run Python bytecode at a time. It's released during I/O.
47. **Threads vs processes vs asyncio?** Threads for I/O with blocking libraries, asyncio for many I/O waits, processes for CPU work.
48. **How does async/await work?** Coroutines yield control at `await`, and an event loop runs whatever is ready.
49. **What is a race condition?** Unsynchronised shared state. Fix it with locks or queues, or by not sharing.
50. **How do you find slow code?** Measure: `timeit`, `cProfile`, `py-spy`, query counts. Then fix the biggest bottleneck.

## Testing & quality ([15](../15_typing_quality/INTERVIEW.md) · [16](../16_testing/INTERVIEW.md))

51. **What is the testing pyramid?** Many unit tests, some integration tests, few end-to-end tests.
52. **What is a pytest fixture?** Setup (and teardown after `yield`) injected into tests by name.
53. **Mock vs stub vs fake?** A stub returns canned answers, a fake is a working light version, and a mock also verifies calls.
54. **Where do you patch?** Where the name is **used**, not where it's defined.
55. **What is TDD?** Red → green → refactor, in small steps.
56. **Is 100% coverage the goal?** No. Test behaviour and edge cases; coverage finds untested code.
57. **How do you test an API endpoint?** `TestClient` or the Django test client, plus overridden dependencies or a test database.
58. **How do you keep code quality high?** ruff, mypy, pre-commit, CI, small PRs and reviews.

## HTTP, REST & web ([18](../18_data_apis_databases/INTERVIEW.md) · [21](../21_web_flask/INTERVIEW.md) · [22](../22_fastapi_in_depth/INTERVIEW.md))

59. **What happens when you type a URL?** DNS → TCP/TLS → HTTP request → server stack → response → render.
60. **What is REST?** Resources at URLs, HTTP methods, stateless requests, status codes, JSON.
61. **PUT vs PATCH vs POST?** PUT replaces, PATCH updates some fields, POST creates.
62. **What is idempotency?** Repeating a request has the same effect as doing it once (GET, PUT, DELETE). POST needs an idempotency key.
63. **Which status codes should you know?** 200, 201, 204, 301/302, 400, 401, 403, 404, 409, 422, 429, 500, 503.
64. **401 vs 403?** 401 means not authenticated; 403 means authenticated but not allowed.
65. **Cookie vs session?** A cookie is data in the browser. A session is server state, usually found by an ID stored in a cookie.
66. **What is CORS?** A browser rule: a page may call another origin only if that API allows it.
67. **WSGI vs ASGI?** WSGI is synchronous. ASGI adds async and WebSockets.
68. **How do you paginate?** limit/offset with a maximum, or a cursor/keyset for large tables.
69. **How do you version an API?** A `/v1/` prefix or a header, and never breaking existing clients.
70. **How do you call an external API safely?** A timeout, `raise_for_status`, retries with backoff for idempotent calls, a session.

## FastAPI & Django ([22](../22_fastapi_in_depth/INTERVIEW.md) · [25](../25_django/INTERVIEW.md))

71. **How does FastAPI validate input?** Type hints and Pydantic. Bad input returns 422 before your code runs.
72. **What is dependency injection in FastAPI?** `Depends()` for DB sessions, auth and pagination, overridable in tests.
73. **`def` vs `async def` endpoints?** Use `async def` only with awaitable I/O. FastAPI runs a plain `def` in a thread pool.
74. **What is middleware?** Code that wraps every request: request IDs, CORS, timing, auth.
75. **What is Django's MVT?** Models, views, templates, with URL routing and middleware around them.
76. **`select_related` vs `prefetch_related`?** A JOIN for FK/one-to-one; a separate IN query for reverse FK and many-to-many.
77. **Are QuerySets lazy?** Yes. They run when evaluated (iteration, `list`, `len`, `bool`).
78. **What are `F()` and `Q()`?** `F()` does DB-side column maths for atomic updates; `Q()` builds OR/NOT conditions.
79. **What are Django signals?** Hooks like `post_save`. Avoid them for core logic because they hide side effects.
80. **What are DRF serializers and viewsets?** A serializer validates and converts to JSON. A viewset plus a router gives full CRUD.

## Databases & SQL ([18](../18_data_apis_databases/INTERVIEW.md) · [23](../23_sqlalchemy_alembic/INTERVIEW.md) · [SQL practice](sql_practice.py))

81. **INNER vs LEFT JOIN?** INNER keeps only matches. LEFT keeps every left row, with NULLs where there's no match.
82. **WHERE vs HAVING?** WHERE filters rows before grouping; HAVING filters groups after aggregation.
83. **What is an index?** A B-tree for O(log n) lookups. It speeds up reads and slows writes.
84. **What is the N+1 problem?** One query plus one more per row. Fix it with eager loading.
85. **What is ACID?** Atomicity, Consistency, Isolation, Durability.
86. **What are isolation levels?** Read uncommitted, read committed, repeatable read and serializable, trading anomalies against concurrency.
87. **How do you prevent lost updates?** An atomic conditional UPDATE, `SELECT ... FOR UPDATE`, or a version column.
88. **How do you prevent SQL injection?** Parameterised queries or an ORM, never string formatting.
89. **How do you deploy migrations safely?** Make them backwards compatible: expand → migrate → contract, reviewed and reversible.
90. **SQL or NoSQL?** SQL for relational data with transactions. NoSQL for flexible schemas or huge scale with simple access patterns.

## Security, deployment & system design ([24](../24_auth_security/INTERVIEW.md) · [26](../26_realtime_tasks_caching/INTERVIEW.md) · [27](../27_deployment/INTERVIEW.md) · [system design](system_design_basics.md) · [git](git_workflow.md))

91. **How do you store passwords?** argon2, scrypt or bcrypt with a salt, never SHA-256 or plain text.
92. **How does JWT work?** A signed, readable, short-lived token. The server verifies the signature and expiry. It's hard to revoke.
93. **XSS vs CSRF?** XSS injects scripts (escape output, add a CSP). CSRF forges requests (CSRF tokens, SameSite cookies).
94. **What is IDOR / broken access control?** Being logged in isn't permission: check ownership on every object.
95. **What caching strategy would you use?** Cache-aside with a TTL, invalidation on write, keys that include everything the result depends on.
96. **When do you use background jobs?** For slow or unreliable work: return 202 and let workers retry idempotent tasks.
97. **Docker image vs container?** An image is a template; a container is a running instance of it.
98. **What is CI/CD?** Every change is tested automatically, and green builds are deployed automatically.
99. **How do you scale a web app?** Stateless replicas behind a load balancer, a cache, DB indexes and replicas, queues, a CDN. Measure first.
100. **Merge vs rebase?** Merge keeps history with a merge commit. Rebase makes it linear: only on your own branch.
