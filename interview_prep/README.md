## How to use it

1. **Two weeks before:** read the Top 100 and mark the ones you can't answer in one breath.
2. For each marked one, open the module's `INTERVIEW.md` and run the lesson code.
3. **Practise out loud.** Interviewers grade how clearly you explain, not just whether you're right.
4. Do the Module 29 exercise under a timer, and one system design practice question per day.
5. Prepare **one project story** (Module 28): what you built, one hard problem, one trade-off, and what you'd improve.
